# How does this chord feel?

A short listening test: rate single piano chords for nostalgia, melancholy and happiness (1–5).
Open the page: https://jiatong-liu.github.io/chord-feel-test/

Chord-emotion scale follows Lahdelma & Eerola (2016), *Single chords convey distinct emotional
qualities to both naive and expert listeners*. Generated from a private project; edit there, not here.
